#Personal portfolio website
A full-stack personal portfolio website built using React, Node.js, Express.js, and MongoDB.

##Features
- Responsive portfolio design
- About Me and Skills sections
- Projects and Education timeline
- Contact form connected to MongoDB
- Backend API using Express.js

##tech stack
- Frontend: React, Vite, CSS, Framer Motion
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Version Control: Git and GitHub

##project structure
- client/ - React frontend
- server/ - Express backend

##Run locally

###backend
1. Open a terminal in the project folder.
2. Run:

    cd server
    npm install
    npm run dev

3. Ensure server/.env contains your MongoDB connection string and PORT=5000.

###frontend
Open a second terminal in the project folder and run:

    cd client
    npm install
    npm run dev

Open the local URL displayed in the terminal.

##security
Never upload .env files, passwords, or database credentials to GitHub.
